Polenta Folder Player

Download Portable Download Installer

Description

Polenta Folder Player is a modern, compact directory audio player for Windows— inspired by classic folder players like 1by1. Open a folder, browse subfolders, and play tracks one by one without building playlists.

A dense, focused UI keeps folder navigation, the track list, and transport controls in one window: play, pause, stop, previous/next, seek, volume, shuffle, and repeat. When you come back, it resumes the last folder, track, and position.

Platform: Windows 10/11 (x64)
License: Freeware
Version: 1.0.0

Features

  • Folder navigation
    Browse the current path and subfolders, then pick any audio file from the track list.
  • Play one-by-one
    Advance through the folder automatically—no playlist setup required.
  • Full transport
    Play, pause, stop, previous, and next with a seek bar and volume control.
  • Shuffle & repeat
    Shuffle the folder order or repeat when you reach the end.
  • Resume playback
    Remembers the last folder, track, and position so you can pick up where you left off.
  • Portable or installed
    Zip portable build or Windows installer—your choice.

Formats

  • MP3, WAV (PCM 16-bit)

Data storage

Resume state and settings are stored as JSON on your PC. Where they live depends on how you run the app:

  • Portable download: next to the executable. The zip includes PolentaFolderPlayer.deploy.json with portable mode.
  • Installer: under %LOCALAPPDATA%\Polenta Connection\PolentaFolderPlayer. The installer sets installed mode automatically.

Your settings stay on your computer.

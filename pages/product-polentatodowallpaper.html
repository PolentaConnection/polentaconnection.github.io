Polenta ToDo Wallpaper

Download Portable Download Installer

Description

Polenta ToDo Wallpaper shows your daily to-do list in a compact desktop panel on Windows. Keep tasks visible while you work, edit the list when you need to, and control the app from the system tray without cluttering the taskbar.

Platform: Windows 10/11 (x64)
License: Freeware
Version: 1.0.0

Screenshots

Features

  • Desktop to-do panel
    Always-visible task list with edit, save, and cancel controls.
  • System tray control
    No taskbar button or Alt+Tab entry — show, hide, About, and quit from the notification area.
  • Customizable look
    Colors, font size, opacity, and panel size as a percentage of the screen (always centered).
  • Long lists
    Continuous scroll or paginated rotation when tasks exceed the available space.
  • Settings panel
    Adjust appearance and window size from an integrated settings offcanvas.
  • Portable or installed
    Run from a USB folder or install to Program Files with data stored under AppData.

Data storage

Your to-do list and settings are saved in settings.json on your PC. Where that file lives depends on how you run the app:

  • Portable download: next to the executable. The zip includes PolentaToDoWallpaper.deploy.json with portable mode.
  • Installer: under %LOCALAPPDATA%\Polenta Connection\PolentaToDoWallpaper. The installer sets installed mode automatically.

Your data stays on your computer.

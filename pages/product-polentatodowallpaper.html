Polenta ToDo Wallpaper

Download Portable Download Installer

Description

Polenta ToDo Wallpaper shows your daily to-do list in a compact desktop panel on Windows. Keep tasks visible while you work, edit the list when you need to, and control the app from the system tray without cluttering the taskbar. The interface is available in seven languages.

Platform: Windows 10/11 (x64)
License: Freeware
Version: 1.0.0

Screenshots

Features

  • Desktop to-do panel
    Always-visible task list on the wallpaper with edit, save, and cancel controls.
  • Wallpaper integration
    Embedded on the desktop layer behind icons when idle; the panel becomes click-through until you interact with it.
  • Hover to use
    Move the mouse over the panel to activate it; it returns to passive mode when the cursor leaves.
  • System tray control
    No taskbar button or Alt+Tab entry â€” show, hide, About, and quit from the notification area.
  • Multi-language UI
    English, Italian, French, Spanish, German, Arabic and Chinese, plus Automatic to follow your system language.
  • Customizable appearance
    Background, text and accent colors; font size; minimum font size with auto-shrink for long lists; spacing between items; opacity.
  • Panel size and position
    Width and height as a percentage of the screen; horizontal and vertical placement (0â€“100%); Compact, Medium and Large presets; one-click center.
  • Long lists
    Continuous scroll or successive pages when tasks exceed the available space, with adjustable scroll speed or pause between pages.
  • Settings panel
    Adjust language, position, size, typography, overflow behaviour, transparency and colors from an integrated settings panel.
  • About & support
    Built-in About box with version information and an optional donation reminder.
  • Single instance
    Only one copy of the app can run at a time.
  • Portable or installed
    Run from a USB folder or install to Program Files with data stored under AppData.

Data storage

Your to-do list and settings are saved in PolentaToDoWallpaper.settings.json on your PC. Where that file lives depends on how you run the app:

  • Portable download: next to the executable. The zip includes PolentaToDoWallpaper.deploy.json with portable mode.
  • Installer: under %LOCALAPPDATA%\Polenta Connection\PolentaToDoWallpaper. The installer sets installed mode automatically.

Your data stays on your computer.
